# DART Research — 리서치 커넥터

리서치 아티팩트가 **회사명만으로** DART 자료를 가져오게 하는 claude.ai 커스텀 커넥터(MCP 서버)입니다.

- LLM을 부르지 않습니다. OpenDART 무료 API만 읽으므로 서버 비용이 거의 없습니다.
- 기존 '하루에 끝장내기' 앱과 **분리된 Railway 서비스**입니다. 원본 앱은 건드리지 않습니다.
- DART 키는 이 서버의 환경변수에만 있습니다. 팀원은 키 없이 커넥터만 켜면 됩니다.

## 가져오는 자료

| 출처 | 내용 |
| --- | --- |
| S1 DART 기업개황 | 회사명, 대표이사, 설립일, 본점, 상장 구분, 업종코드, 결산월 |
| S2 최근 사업보고서 | 회사의 개요, 회사의 연혁, 사업의 개요, 주요 제품, 원재료 및 생산설비, 매출 현황, 기타 참고사항(산업·시장), 최대주주(보통주), 주요 재무 3개년 |
| S2 (사업보고서가 없을 때) | 최근 감사보고서 주석의 일반사항 |

정정공시가 있으면 가장 최근 것을 씁니다. 같은 공시 원문은 한 번 받은 뒤 다시 받지 않고, 회사 목록은 하루에 한 번만 받습니다.

## 재무 도구 (WACC 대용기업 등)

claude.ai 대화에서 커넥터를 켜고 그냥 요청하면 됩니다. 예: "한솔케미칼, 솔브레인, OCI의 2025 사업보고서 기준 이자부부채와 장부가 D/E 뽑아줘"

| 도구 | 하는 일 |
| --- | --- |
| `capital_structure` | 여러 회사(최대 15곳) 한 번에: 이자부부채(계정별 근거), 현금, 순차입금, 부채총계, 자본총계, 부채비율, 장부가 D/E, 유효세율, 금융원가, 발행·자기·유통 보통주식수 |
| `financial_statements` | 한 회사의 공시 재무제표(BS·IS·CF 등) 전체 계정, 당기·전기 |

- 이자부부채에 넣는 것: 단기차입금, 유동성장기차입금(부채), 사채(전환·교환·BW 포함), 장기차입금, 기업어음, 리스부채(`include_lease=false`로 제외 가능)
- 합산하지 않고 `review_items`로 따로 보여 주는 것: 사채할인발행차금·전환권조정 등 조정 계정, 상환우선주·우선주부채, 파생상품부채
- 연결 재무제표가 없으면 별도로 대신 가져오고 그 사실을 notes에 적습니다.
- 시가 D/E에 필요한 주가는 DART에 없습니다. 유통보통주식수를 함께 주므로 평가기준일 주가만 곱하면 됩니다.
- XBRL 재무제표가 있는 회사(상장사 등)만 됩니다.

## 1. Railway에 배포

1. 이 폴더를 GitHub 새 저장소(또는 기존 저장소의 별도 폴더)에 올립니다.
2. Railway → **New Service → GitHub Repo**에서 선택합니다. 폴더로 올렸다면 Settings → Root Directory에 폴더명을 넣습니다.
3. **Variables**에 아래 두 값을 넣습니다.

   | 이름 | 값 |
   | --- | --- |
   | `DART_API_KEY` | 발급받은 OpenDART 키 |
   | `CONNECTOR_SECRET` | 영문·숫자 24자 이상 임의 문자열 (예: 비밀번호 생성기로 32자) |

4. Settings → Networking → **Generate Domain**으로 주소를 만듭니다. 예: `dart-research-production.up.railway.app`
5. 배포가 끝나면 `https://<도메인>/health`에서 `{"ok": true}`가 보이는지 확인합니다.

시작 명령과 헬스체크는 `railway.json`에 들어 있습니다.

## 2. claude.ai에 커넥터 등록

커넥터 주소: `https://<도메인>/<CONNECTOR_SECRET>/mcp`

- **이름은 정확히 `DART Research`로 등록합니다.** 아티팩트가 이 이름으로 커넥터를 찾습니다.
- Team/Enterprise: 조직 관리자가 설정 → 커넥터에서 커스텀 커넥터로 한 번 추가하면 팀원은 켜기만 하면 됩니다.
- 개인 계정: 설정 → 커넥터 → 커스텀 커넥터 추가.
- 인증 방식은 "없음"을 고릅니다. 주소의 비밀값이 접근 제한 역할을 합니다. 주소가 밖으로 새면 `CONNECTOR_SECRET`을 바꾸고 커넥터 주소를 새로 등록하세요.

## 3. 확인

리서치 아티팩트 → 2단계 자료 → 회사명 입력 후 **DART에서 찾기** → 회사 선택 → **자료 가져오기**.
처음 한 번은 커넥터 사용 허용을 묻습니다.

## 한도와 비용

- OpenDART: 키당 하루 2만 건. 회사 하나에 약 5~6건을 씁니다(캐시되면 더 적게).
- Railway: 요청이 없을 때 거의 놀고 있는 작은 서비스입니다.
