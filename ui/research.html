회사개요 리서치

회사명을 넣으면 DART에서 회사의 기초 자료와 최근 재무 정보를 불러옵니다. 외부 자료 링크와 PDF를 읽어 회사의 이해 장표 초안을 만듭니다. 사용자 검토 이후 보고서로 보내기를 누르면 DCF Build 앱의 보고서 장표에 반영됩니다. 작성 코스트는 이 화면을 쓰는 사용자의 Claude 사용량에서 차감됩니다.

예시 가상 회사(가나다케미칼) 자료와 결과가 채워져 있습니다.
보고서 앱의 보고서에 연결됨 · 아래 보고서로 보내기를 누르면 이 보고서에 들어갑니다.
장표별로 들어갈 칸 보기 (지분가치·PPA·사용가치 공통 양식)

자료

    시장 현황용 자료 · 기사·보고서 링크를 붙여넣거나, 가지고 있는 PDF 파일(산업 보고서 등)을 올리세요.

      첨부한 링크 및 PDF 파일을 토대로 데이터를 읽습니다. 자료 추가 기능으로 사용자가 직접 데이터를 붙여넣을 수 있습니다. 데이터 준비가 완료되면 AI가 사업의 이해 초안을 작성합니다.

      U1 재무정보 장표 · DART 공시 재무제표 연간 2개년 (평가기준일 열은 직접 입력) · 사업연도를 비우면 가장 최근 사업보고서 · Claude 사용량 들지 않음
      2

      작성

      한 번 누를 때 한 번만 호출합니다. 글자 수 초과 같은 오류는 아래 검토 화면에서 바로 고치면 추가 비용이 들지 않습니다.

      3

      검토·보내기

      보고서 앱으로 바로 보내기 — 보고서 앱 화면의 '보고서 ID'를 붙여넣거나, 앱의 '리서치 화면 열기'로 들어오면 자동으로 채워집니다.

      대용기업을 검색하면 DART 데이터에서 이자부부채를 추출하여 합산하고, 자본구조·유통주식수 등을 표로 출력합니다. 평가기준일의 주가를 기재하면 시가 기준 자본구조가 계산되고, 엑셀로 내려받을 수 있습니다.

      자본구조

      회사명을 클릭하여 DART 원문과 반드시 대조·검토하세요.

      (*) 순차입금 = 적용 이자부부채 − 현금및현금성자산. 적용 이자부부채를 고치면 함께 바뀌고, 리스부채는 위 '리스부채 포함' 선택을 따릅니다. 단기금융상품 등 다른 금융자산은 빼지 않았습니다.

      금액 단위 백만원. 적용 이자부부채는 주석 확인 후 고칠 수 있고, 주가(평가기준일 종가)를 넣으면 시가총액과 Debt / Equity(= 이자부부채 ÷ (시가총액 + 비지배지분))가 계산됩니다. 회사명을 누르면 넣은 계정과 출처가 보입니다.

      3

      주요 재무 지표

      상대가치 평가용 benchmark · 단위 백만원

      LTM = 직전 사업연도 + 최근 보고서 당기 누적 − 전기 동기 누적. 최근 공시가 사업보고서인 회사는 LTM과 연간이 같습니다. 감가상각비는 현금흐름표의 감가상각비·무형자산상각비·사용권자산상각비 합계이고, 본문에 없는 회사는 주석에서 확인하세요. EBITDA = 영업이익 + 감가상각비. 회사명을 누르면 항목별 공시 계정과 LTM 계산 근거가 보입니다. 지배주주귀속순이익이 따로 없는 회사(별도 재무제표 등)는 당기순이익을 넣고 표시합니다.
